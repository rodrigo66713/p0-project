# Projeto P0: Primeiro Fluxo de LLM

## Problema  

Um aluno de Sistemas de Informação busca classificar a lista de avaliações recebidas pelos professores nas seguintes categorias:
- Avaliações escritas;
- Avaliações práticas;
- Apresentações;
- Entregas;

### Justificativa

O uso de uma LLM, nesse caso, é justificável, tendo em vista que ela é capaz de interpretar as atividades recebidas, e segregá-las nas seções supracitadas. 
Com isso, busca-se eliminar a necessidade do professor especificar qual tipo de atividade será delegada ao aluno, além de facilitar a organização do aluno, abrindo portas para o aluno saber quais são os tipos de atividade os quais ele deve priorizar ao longo de seu período letivo.
